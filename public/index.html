工作原理

01

浏览器直连 DoH

页面用 fetch 直接请求各家 DoH JSON 端点，查询参数不经过任何第三方服务器。

02

归一化记录

03

常见问题

为什么和本地 dig 的结果不完全一样？
解析结果受递归线路与 TTL 缓存影响。刚改完解析时，各家缓存还没过期，短期内出现差异是正常的；等 TTL 过期后通常自动一致。
为什么有的解析商显示查询失败？
查询由你的浏览器直接发出，结果取决于你当前网络到该端点是否可达。部分公共 DNS 的 DoH 端点在国内网络会被阻断，也可能被浏览器的跨域策略拦下，失败时卡片会写明原因。
为什么只有四家？
纯前端必须依赖对方放行 CORS。腾讯 DNSPod、360 安全 DNS 的 DoH 不返回跨域头，Quad9 也不支持 JSON 接口，浏览器侧无法查询，因此默认只保留能直连的四家。你的私有端点若返回 JSON 且带 Access-Control-Allow-Origin，填进「自定义」就能一起比对。
会记录我的查询吗？
没有服务端，也没有日志。查询请求由你的浏览器直接发往解析商，本站只负责展示。解析商自身是否会记录，取决于各家的隐私政策。
支持哪些记录类型？
A、AAAA、CNAME、MX、TXT、NS、SOA、CAA 八种，「全部」会一次性并发查询这八类。
